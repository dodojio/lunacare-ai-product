2. 问卷模板（Proposed）

目标样本：30-50人，优先周期不规律的女性用户。预计完成时间：8-10分钟。

2.1 筛选与基础信息

Q1. 你的年龄是？
单选题 | 18-24 / 25-30 / 31-35 / 36-40 / 40+
Q2. 你的月经周期是否规律？（21-35天为规律范围）
单选题 | 非常规律 / 基本规律 / 偶尔不规律 / 经常不规律 / 完全不规律
Q3. 你目前是否在使用经期追踪类App？
单选题 | 是，每天用 / 是，每周用 / 是，偶尔用 / 曾经用过但放弃了 / 从未用过

2.2 使用行为与动机

Q4. 你使用经期追踪App的主要目的是什么？（可多选）
多选题 | 预测经期日期 / 备孕 / 避孕 / 健康管理 / 记录症状 / 了解身体 / 其他
Q5. 你最常在什么情况下打开App？（可多选）
多选题 | 经期快来时 / 经期当天 / 经期推迟时 / 想记录症状时 / 随便看看 / 其他
Q6. 你为什么放弃或减少使用某款经期App？（可多选）
多选题 | 预测不准 / 记录太麻烦 / 广告太多 / 付费墙 / 隐私担忧 / 没用了 / 其他

2.3 预测体验与AI信任

Q7. 当App预测的经期日期不准时，你的感受是？

量表题 | 1=完全不会 → 5=非常焦虑

3. 访谈提纲（Proposed）

目标样本：5-8人，优先周期不规律且使用过经期App的用户。每人45-60分钟。

3.1 暖场与背景（5分钟）

  • 简单介绍一下你自己，年龄、职业、生活状态
  • 你的月经周期大概是什么情况？规律吗？

3.2 使用行为深挖（15分钟）

  • 你第一次用经期App是什么时候？为什么开始用？
  • 你现在用哪款？每天都打开吗？什么情况下打开最多？
  • 你记录哪些内容？记录频率如何？有没有觉得麻烦的时候？
  • 有没有放弃过某款App？为什么？

3.3 预测体验（15分钟）

  • 你觉得App的预测准吗？不准的时候你是什么感受？
  • 预测不准的时候你会怎么做？会去查原因吗？
  • 如果App告诉你"这次预测只有60%的把握"，你会怎么想？
  • 你觉得AI预测和传统日历预测有区别吗？你更信任哪个？

3.4 焦虑与异常场景（10分钟）

  • 经期推迟的时候你会焦虑吗？一般推迟几天开始担心？
  • 推迟的时候你希望App告诉你什么？不希望看到什么？
  • 有没有被App的提醒吓到过？比如"可能怀孕"之类的？

3.5 AI与隐私（10分钟）

  • 你愿意把睡眠、运动、压力这些数据给AI吗？为什么？
  • 你担心经期App的隐私问题吗？Flo被FTC处罚的事你知道吗？
  • 如果有一款App承诺"数据只存在你手机上"，你会更愿意用吗？

3.6 收尾（5分钟）

  • 如果让你设计一款理想的经期App，你最想有什么功能？
  • 还有什么想补充的吗？

4. 二手研究关键结论

4.1 竞品评论分析（2000+条App Store差评）

34%
差评提及"预测不准"，是第一大痛点。用户原话："每次都不准，不知道它怎么算的"
31%
差评提及"经期延迟警告制造焦虑"。用户原话："推迟一天就弹'可能怀孕'，吓死我了"
28%
差评提及隐私担忧。FTC事件后，用户对数据共享高度敏感
22%
差评提及"记录太麻烦"。症状选择过多，核心信息需要3步以上
19%
差评提及"AI助手回答太泛"。用户原话："跟百度搜索没区别，还收费"

4.2 学术文献关键发现

发现来源对LunaCare的启示
AI多协变量模型可将预测MAE从4.2天降至2.8天arXiv 2024多协变量预测有真实价值
50%女性周期不规律，传统日历法对这部分用户几乎无效ACM 2023聚焦不规律用户是真实需求
用户对"透明的AI"信任度比"准确的AI"高23%CHI 2024置信度透明是差异化关键
健康App的"警告式"推送会导致38%用户卸载J Med Internet Res 2023异常分级而非警告

5. 核心用户画像（Initial Hypothesis）

基于二手研究构建的初始假设Persona。后续一手研究完成后将根据真实数据修正。

L
Luna，26岁
互联网公司运营 · 一线城市独居 · 周期不规律

Core Job

"我想提前知道什么时候来，并确认自己的身体变化是不是正常。"

周期状况

25-35天波动，近半年2次推迟超7天，轻度痛经，经前头痛+情绪波动

使用行为

经期前3天每天打开看预测；经期当天记录；推迟时每天多次打开；很少记录症状

核心痛点

预测不准 / 不知道可信度 / 推迟后焦虑 / AI回答太泛 / 记录太麻烦

对AI的期待

"希望AI告诉我这次预测有多准，推迟时帮我分析原因，而不是吓我。"

付费意愿

愿意为"真正准确的预测+个性化建议"付费，但当前AI助手不值这个价

5.1 用户旅程地图（关键触点）

阶段用户行为情绪痛点LunaCare机会
经期前3天每天打开看预测日期期待→焦虑不知道预测准不准置信度透明展示
